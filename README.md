# Linxira Wiki

The official Linxira OS wiki, built with MkDocs (Material theme) and published
at **https://linxira-os.github.io/linxira-wiki/**.

The wiki records only what is unique to Linxira OS — the installer, Welcome,
Shelly, Config Hub, the software catalog, workflows, and branding — and
discusses each project's design rationale: why it exists, its responsibility
boundaries, when to use which tool, and the permission model. Generic Arch
Linux, KDE, systemd, pacman, and hardware topics are delegated to the
[Arch Wiki](https://wiki.archlinux.org/). Project-internal designs, data
structures, and implementation decisions live in each project's own repository,
not here.

## Contents

- **首页**: what Linxira OS is (a KDE Plasma personal scientific workstation
  distribution built directly on Arch Linux) and the documentation scope.
- **项目总览**: the cross-project map — Config CLI, Components, Recovery
  Diagnostics, Workspace Guard, and the WSL distribution — with the ownership
  table generated from `linxira-os/governance/repositories.yaml`.
- **Linxira 特性**: Direct Arch architecture, branding system, Config Hub,
  preinstalled tools, and workflow templates (scientific, AI, development,
  container, bioinformatics).
- **外部链接**: pointers to the Arch Wiki and notes on other distributions.

## Two synchronized forms, one source of truth

- `docs/` — the human-readable MkDocs site (Chinese).
- `ai/` — the machine-readable form for AI agents: `manifest.json` index plus
  `topics/*.md` (one page per topic, at most 60 lines: when to use it, how to
  invoke it, which privileges are required). Both forms are generated from the
  same content; there is no second source of truth.

`ai/manifest.json` is generated by `scripts/generate-manifest.py` from
`linxira-os/governance/repositories.yaml` — do not edit it by hand. CI
verifies that the generated manifest matches its data sources.

## CLI reader

`cli/linxira-wiki` is a read-only Bash reader for the installed wiki
(default root `/usr/share/linxira/wiki`). Every subcommand is read-only: no
privilege escalation, no authorization, no file writes.

```bash
linxira-wiki manifest              # print the manifest
linxira-wiki list                  # list all pages
linxira-wiki show workspace-guard  # read one topic
linxira-wiki search privilege      # locate pages by keyword
```

## Local development

```bash
pip install -r requirements.txt   # mkdocs + mkdocs-material
mkdocs serve                      # http://localhost:8000
```

The published site is deployed from this repository to
https://linxira-os.github.io/linxira-wiki/.

## 简体中文

Linxira OS 官方 wiki，使用 MkDocs（Material 主题）构建，发布于
**https://linxira-os.github.io/linxira-wiki/**。

本 wiki 只记录 Linxira OS 独有的内容 —— 安装器、Welcome、Shelly、Config Hub、
软件目录、工作流与品牌系统 —— 并讨论每个项目的设计缘由：为什么存在、职责边界、
何时用哪个工具、权限模型。通用 Arch Linux、KDE、systemd、pacman 与硬件话题请
参考 [Arch Wiki](https://wiki.archlinux.org/)。具体项目的内部设计、数据结构与
实现决策在各项目自己的仓库，不在本 wiki。

## 内容

- **首页**：Linxira OS 是什么（直接基于 Arch Linux 构建的 KDE Plasma 个人科学
  工作站发行版）与文档范围。
- **项目总览**：跨项目地图 —— Config CLI、Components、恢复诊断、工作区守护与
  WSL 发行版 —— 附由 `linxira-os/governance/repositories.yaml` 生成的归属表。
- **Linxira 特性**：Direct Arch 架构、品牌系统、配置中心、预装工具与工作流模板
  （科学、AI、开发、容器、生物信息）。
- **外部链接**：Arch Wiki 指引与其他发行版笔记。

## 两种同源形态，唯一真相源

- `docs/` —— 面向人的 MkDocs 站点（中文）。
- `ai/` —— 面向 AI 代理的机器可读形态：`manifest.json` 索引加 `topics/*.md`
  （每个主题一页，不超过 60 行：什么时候用、怎么调、需要什么权限）。两种形态
  由同一批内容生成，没有第二份真相。

`ai/manifest.json` 由 `scripts/generate-manifest.py` 从
`linxira-os/governance/repositories.yaml` 生成 —— 不要手工编辑。CI 会校验生成
的 manifest 与其数据源一致。

## CLI 阅读器

`cli/linxira-wiki` 是已安装 wiki（默认根目录 `/usr/share/linxira/wiki`）的只读
Bash 阅读器。全部子命令只读：不提权、不需要授权、不写任何文件。

```bash
linxira-wiki manifest              # 打印 manifest
linxira-wiki list                  # 列出全部页面
linxira-wiki show workspace-guard  # 读一个主题
linxira-wiki search privilege      # 按关键词定位页面
```
