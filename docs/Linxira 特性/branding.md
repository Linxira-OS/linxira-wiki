# 品牌系统

Linxira OS 使用自有品牌标识，完全独立于上游发行版。

## 品牌资产

所有品牌资产存放在 `linxira-artwork` 仓库中。

### Logo 变体

| 文件 | 用途 |
|------|------|
| `linxira-logo.svg` | 主 Logo |
| `linxira-icon.svg` | 图标 (64×64) |
| `linxira-lockup.svg` | Logo + 文字组合 |

### 壁纸

- 深色主题: `linxira-wallpaper-dark.svg`
- 浅色主题: `linxira-wallpaper-light.svg`
- KDE 壁纸主题: `usr/share/wallpapers/LinxiraOS/`

### 品牌色

| 颜色 | 用途 |
|------|------|
| 青绿 `#14b8a6` | 物理、生物 |
| 紫色 `#6366f1` | 化学、计算 |
| 暗蓝 `#0f172a` | 背景、深空 |

## 系统标识

Linxira OS 修改了以下文件以显示自有品牌：

- `/etc/os-release`
- `/etc/lsb-release`
- Calamares branding 描述符
