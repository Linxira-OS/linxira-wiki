# 预装工具

Linxira OS 预装了一系列开发和科研工具，开箱即用。

## 包管理器

| 工具 | 说明 |
|------|------|
| apt | 系统包管理 (基于 Ubuntu LTS) |
| mise | 多语言版本管理 |
| Miniforge3 | 科学计算包管理 (预配置 bioconda + conda-forge) |
| Distrobox | 容器化其他发行版 |
| uv | 快速 Python 包管理 |

## 编程语言

| 语言 | 工具 |
|------|------|
| C/C++ | gcc, g++, gdb, cmake, make |
| Rust | rustup, cargo |
| Go | golang |
| Python | python3, pip (通过 mise/Miniforge 管理) |
| Java | openjdk |
| Node.js | nodejs LTS |
| JavaScript | Bun |

| 类别 | 应用 |
