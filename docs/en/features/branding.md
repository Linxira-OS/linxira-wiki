# Branding system

Linxira OS uses its own brand identity, fully independent of upstream distributions.

## Brand assets

All brand assets live in the `linxira-artwork` repository.

### Logo variants

| File | Purpose |
|------|---------|
| `linxira-logo.svg` | Primary logo |
| `linxira-icon.svg` | Icon (64×64) |
| `linxira-lockup.svg` | Logo plus wordmark |

### Wallpapers

- Dark theme: `linxira-wallpaper-dark.svg`
- Light theme: `linxira-wallpaper-light.svg`
- KDE wallpaper theme: `usr/share/wallpapers/LinxiraOS/`

### Brand colours

Canonical Scale L uses the colours below. Colour values are written as uppercase hex in both code and design assets.

| Colour | Value |
|--------|-------|
| Scale L teal | `#20B8B0` |
| Scale L coral | `#F36F5D` |
| Scale L ink | `#0E1417` |

## System identity

Linxira OS modifies the following files to present its own branding:

- `/etc/os-release`
- `/etc/lsb-release`
- The Calamares branding descriptor
