# Bio SDK (linxira-bio-sdk)

!!! warning "Under construction, incomplete"
    This page is a placeholder. It contains no usage and does not promise a stable
    interface.

Linxira Bio SDK is a local-first, agent-native bioinformatics toolkit: tested skills,
CLI, SDK and tool contracts for routine analyses, so each run does not start from a newly
generated script. The repository is still in development, the CLI contract is not stable
and the Python SDK remains planned. This wiki has no verified user documentation for it.

- Status: placeholder; not yet covered by the wiki's software guides.
- Repository: [Linxira-OS/linxira-bio-sdk](https://github.com/Linxira-OS/linxira-bio-sdk)

Until the repository publishes a stable CLI and SDK contract, treat nothing here as an
executable promise.
