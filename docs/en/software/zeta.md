# Zeta (linxira-zeta)

!!! warning "Under construction, incomplete"
    This page is a placeholder. It contains no usage and does not promise that a usable
    build is currently delivered.

Zeta is a Bun-native coding-agent distribution built on the OMP runtime. It aims to put
the terminal, a local browser workbench and a desktop shell on one session tree and one
settings model. The repository is still under active development, and this wiki has no
verified user documentation for it yet.

- Status: placeholder; not yet covered by the wiki's software guides.
- Repository: [Linxira-OS/linxira-zeta](https://github.com/Linxira-OS/linxira-zeta)

Until the repository publishes a stable installation and usage contract, treat nothing
here as an executable promise.
