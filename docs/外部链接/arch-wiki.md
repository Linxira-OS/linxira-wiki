# Arch Wiki

**Arch Wiki** 是 Linux 世界的维基百科，几乎涵盖所有发行版的通用 Linux 问题。

## 为什么参考 Arch Wiki

虽然 Linxira OS 基于 Ubuntu/Mint，但 Arch Wiki 的文档质量是 Linux 社区最高的：

- 覆盖面广：从基础配置到高级调优
- 更新及时：社区活跃，文档经常更新
- 通用性强：大部分内容适用于所有发行版

## 推荐阅读

- [Arch Wiki 首页](https://wiki.archlinux.org/)
- [General recommendations](https://wiki.archlinux.org/title/General_recommendations)
- [List of applications](https://wiki.archlinux.org/title/List_of_applications)
- [Power management](https://wiki.archlinux.org/title/Power_management)
- [Network configuration](https://wiki.archlinux.org/title/Network_configuration)

## 注意事项

Arch Wiki 中的部分内容可能需要适配：

- 包管理命令：`pacman` → `apt`
- 配置文件路径可能略有不同
- 某些 AUR 包需要从其他来源安装
